# ВОЛЬТ — демо-сайт выездного автоэлектрика

Одностраничный лендинг для мастера по автомобильной электрике: услуги, цены, отзывы, FAQ и форма заявки на выезд. Сделан как демо для презентации — без сборщиков, фреймворков и внешних библиотек.

**Демо:** https://kipatich.github.io/avtoelektrik-demo/

> Это демонстрационный проект. Форма по умолчанию не отправляет данные на сервер, телефон и отзывы — примеры. Перед реальным запуском замените контакты и подключите приём заявок.

---

## Что внутри

- Тёмный «автомобильный» дизайн с акцентом на электрику и диагностику.
- Адаптивная вёрстка: десктоп, планшет, телефон (проверено от 320 px).
- Интерактивный блок симптомов: 6 сценариев с причинами, ценой и временем.
- 6 карточек услуг, процесс работы, статистика, таблица цен, отзывы и FAQ.
- Форма заявки с маской телефона, валидацией и согласием на обработку данных.
- Демо-уведомление в стиле Telegram — показывает, как заявка придёт мастеру.
- Мобильная панель «Позвонить / Оставить заявку», меню, модальное окно политики.
- Локальные шрифты Unbounded и Manrope — без обращений к Google Fonts.
- `noindex` и `robots.txt` — чтобы демо с примерными данными не попало в поиск.

## Быстрый запуск

Из папки проекта:

```powershell
python -m http.server 4173
```

Откройте `http://127.0.0.1:4173/`.

Можно и просто открыть `index.html` в браузере, но локальный сервер корректнее для шрифтов и `localStorage`.

## Как поменять данные

Почти всё меняется в одном файле — [`assets/js/config.js`](assets/js/config.js):

| Параметр | Что это |
|---|---|
| `brand` | Название на логотипе и в футере |
| `tagline` | Подпись под названием |
| `phoneDisplay` | Телефон как он выглядит на сайте |
| `phoneRaw` | Телефон для ссылки `tel:` (только цифры, с `+7`) |
| `whatsapp` | Номер для `wa.me` (только цифры) |
| `telegram` | Username в Telegram без `@` |
| `city` / `cityShort` | Город в текстах и контактах |
| `hours` | График работы |
| `email` | Почта |
| `leadEndpoint` | URL приёмника заявок (необязательно) |

После изменения обновите страницу.

Тексты, цены и отзывы лежат прямо в `index.html`. Цены в таблице и карточках лучше менять парой, чтобы не было расхождений.

### Что заменить перед реальным запуском

- [ ] Название, телефон, WhatsApp, Telegram, город и почту.
- [ ] Цены и состав услуг.
- [ ] Статистику («12 лет», «1800+ выездов») — сейчас это пример.
- [ ] Отзывы и рейтинг — сейчас это пример.
- [ ] Политику конфиденциальности под реального оператора данных.

- [ ] Добавить реальные реквизиты, если они нужны по закону.

## Форма заявки

### Демо-режим (по умолчанию)

`leadEndpoint: ""`.

Заявка сохраняется в `localStorage` браузера под ключом `volt_demo_leads`, показывается экран успеха и всплывающее уведомление «как в Telegram». Никуда не отправляется. Это удобно для презентации: можно заполнить форму при друге и сразу показать, как выглядит заявка.

Посмотреть пример уведомления можно и без заполнения — ссылка «Как придёт заявка?» под формой.

### Реальный приём заявок

Самый быстрый вариант без своего сервера — Formspree, Getform или аналоги:

1. Зарегистрируйтесь и создайте форму.
2. Получите endpoint вида `https://formspree.io/f/xxxxxxxx`.
3. Укажите его в `config.js`:

```js
leadEndpoint: "https://formspree.io/f/xxxxxxxx"
```

Форма отправит JSON с полями `name`, `phone`, `car`, `problem`, `comment`, `consent`, `id`, `page`. При успехе покажется экран «Заявка отправлена», при ошибке — сообщение с телефоном.

> Для Telegram-бота не храните токен в `config.js`: любой посетитель увидит его в исходниках. Нужен маленький бэкенд (Cloudflare Worker, VPS, n8n, Make), который примет заявку и отправит её в Telegram. Токен хранится только на сервере.

### Куда приходит заявка

В демо — в `localStorage` и в красивый toast. В рабочей версии рекомендую связку:

`форма → Cloudflare Worker / Formspree → Telegram-бот + Google Sheets / CRM`

Так мастер получает уведомление на телефон и не теряет заявки.

## Публикация на GitHub Pages

Проект уже опубликован по адресу выше. Если нужно повторить:

1. Создайте публичный репозиторий, например `avtoelektrik-demo`.
2. Загрузите содержимое этой папки в ветку `main` (не саму папку, а файлы внутри).
3. В репозитории: **Settings → Pages → Build and deployment**.
4. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**.
5. Сохраните. Через минуту сайт будет доступен по адресу `https://<username>.github.io/avtoelektrik-demo/`.

Файл `.nojekyll` уже добавлен — он отключает обработку Jekyll и не даёт GitHub Pages игнорировать файлы, начинающиеся с подчёркивания.

## Технические детали

- Чистый HTML + CSS + JavaScript, без зависимостей и сборки.
- Шрифты self-hosted, кириллица и латиница.
- SVG-иллюстрация автомобиля и иконки нарисованы вручную, без стоковых фото.
- Анимации отключаются при `prefers-reduced-motion`.
- Есть skip-link, focus-visible, aria-атрибуты, клавиатурная навигация по симптомам.
- Телефон маскируется в `+7 (999) 000-00-00`, проверяется длина и первая цифра.
- Поддержка `localStorage` обёрнута в try/catch — демо не падает в приватном режиме.
